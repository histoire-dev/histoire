# Official Plugins

- [@histoire/plugin-a11y](./a11y.md): axe-core accessibility audits and optional story tests
- [@histoire/plugin-designs](./designs.md): Figma, Penpot, Sketch, image and iframe designs next to stories
- [@histoire/plugin-vue](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-vue): Vue 3 (support plugin)
- [@histoire/plugin-vue-devtools](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-vue-devtools): Devframe-based Vue DevTools for Vue story frames
- [@histoire/plugin-nuxt](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-nuxt): Nuxt 3 and 4
- [@histoire/plugin-quasar](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-quasar): Quasar CLI (Vite)
- [@histoire/plugin-svelte](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-svelte): Svelte 4/5 and SvelteKit 2/3
- [@histoire/plugin-react](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-react): React 18/19 (support plugin; requires a project JSX plugin such as `@vitejs/plugin-react`)
- [@histoire/plugin-percy](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-percy): Visual regression testing with Percy
- [@histoire/plugin-screenshot](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-screenshot): Visual regression testing (simple)
