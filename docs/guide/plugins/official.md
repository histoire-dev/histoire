# Official plugins

- [@histoire/plugin-a11y](./a11y.md): axe-core accessibility audits and optional story tests
- [@histoire/plugin-designs](./designs.md): Compare stories with design files, images, or embedded pages
- [@histoire/plugin-vue](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-vue): Vue 3
- [@histoire/plugin-vue-devtools](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-vue-devtools): Vue DevTools for story frames in development
- [@histoire/plugin-nuxt](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-nuxt): Nuxt 3 and 4
- [@histoire/plugin-quasar](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-quasar): Quasar CLI (Vite)
- [@histoire/plugin-svelte](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-svelte): Svelte 4/5 and SvelteKit 2/3
- [@histoire/plugin-react](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-react): React 18 and 19 with the project's JSX plugin
- [@histoire/plugin-percy](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-percy): Visual regression testing with Percy
- [@histoire/plugin-screenshot](https://github.com/histoire-dev/histoire/tree/main/packages/histoire-plugin-screenshot): Variant screenshots during builds
