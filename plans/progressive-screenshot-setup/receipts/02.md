## Changes

- Added shared `HistoireBrowserConfig`/`HistoireBrowserSource` and portable screenshot setup DTOs. `HistoireConfig.browser` defaults to `auto`, validates strict source/path combinations, resolves custom paths against project root, and stays out of both development and static public config.
- Added immutable `BrowserSetupPolicy`, private driver/candidate types, and the `ScreenshotSetupOwner`/`CaptureBrowserLease` contracts for slice 03. Lease contract includes optional process discard for later pool quarantine when context cleanup is uncertain.
- Added project-first driver resolution in the required order: project `playwright`, project `playwright-core`, Histoire fallback `playwright`, Histoire fallback `playwright-core`. Metadata-only identity resolution imports nothing and reads SemVer from the selected real entry's matching package boundary. Runtime resolution imports the chosen driver and checks only public `chromium.launch` and `chromium.executablePath`; it never launches and does not silently replace an invalid preferred package.
- Runtime imports are pinned by real entry path and manifest version for the process. Concurrent imports share one pending result; failures remain non-retryable at that path because Node can cache failed modules. A changed manifest version at an imported path reports `driver-version` without re-importing, while metadata-only identity still reflects the fresh version.
- Added finite candidate inventory. Playwright 1.49.0+ uses unknown-presence headless shell, then full Chromium; older versions use regular bundled Chromium as source `chromium` with `{ headless: true }`, then branded channels, because those drivers have no separate shell. Explicit shell is unavailable on old drivers. Chrome/Edge checks use only stable paths that match Playwright channel resolution on Windows, macOS, and Linux. No cache scan, PATH lookup, install, process, or network call. Candidate tests cover 1.48.2, 1.49.0, 1.49.0-beta.1, and 1.59.1.
- Parent added `playwright-core` as optional peer (`^1.0.0`) with optional peer metadata. Existing Vitest test prerequisites remain unchanged.
