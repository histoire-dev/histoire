# Slice 08 receipt — optional screenshot browser reuse

Status: implemented with bounded live-browser acceptance. Parent owns final combined acceptance; this receipt does not declare M4 complete.

## Changes

- Added validated `browser.reuse` and `browser.idleTimeoutMs` config fields. Reuse is off by default; timeout defaults to 30,000 ms, accepts integer values from 1,000 to 300,000, and is rejected unless reuse is explicitly enabled.
- Added a generation-, driver-, and source-scoped browser pool. It keeps one browser process, assigns exclusive operation leases, and always relies on per-capture fresh contexts. Refresh retires idle processes and allows active captures to release against their original process.
- Added distinct healthy release and uncertain-context discard. A pool cleanup failure is retained as terminal across refresh; disconnect clears setup proof for later explicit work. Story capture is not replayed after disconnect or failure.
- Kept Node deployments process-fresh; reuse environment flags are ignored. Added browser reuse configuration docs and focused lifecycle tests.

Relevant implementation: `packages/histoire/src/node/runtime/browser/setup/{pool,reuse,lease,owner,policy}.ts`, `packages/histoire/src/node/config/browser.ts`, and `packages/histoire-shared/src/types/config-browser.ts`. Owner remains 299 lines; pool remains 293 lines.
