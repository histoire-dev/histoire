## Limitations

- Package JSON diff simulates package-manager output; package managers can format/reorder files differently and update lockfiles/node_modules. Plan warns; slice 06 must compare actual output and report mismatch without treating it as installation failure.
- Planner does not resolve binaries, run package code, execute migrations, write config, acquire job ownership or perform rollback.
- Import-use analysis is conservative: an identifier with same spelling in another syntax position may retain an otherwise-unused import.
- Ambiguous duplicate factory calls, arbitrary array spreads and variable arrays stay manual. Disabled entries can be removed; options edits on disabled entries stay manual to preserve marker metadata.
- Very large diffs can exceed UI channel capacity; handler returns a correlated `failed` error rather than silently dropping reply.
